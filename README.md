# 水下考古样本移交台

直接打开 `index.html` 使用（纯前端，数据保存在浏览器 localStorage）。

## 业务规则

- **唯一标识**：样本以「潜次 + 编号」唯一，重复登记会被拒绝。
- **三阶段不可跳步**：出水登记（待复核）→ 封存复核（待移交）→ 入库移交（已入库）。登记后不能直接入库；存在待确认修订时不能移交。
- **复核修订留版**：复核时修改深度、朝向或保存状态，旧版保留在「版本留档」，并生成一条**待确认修订**；确认后新版才生效。三项均不修改则复核直接通过。
- **待确认修订唯一**：同一记录同时只能有一条待确认修订；重复确认沿用首次结果（修订消失后再次确认不会再改写数据）。
- **入库后再修订失效**：已入库样本修改这三项，原入库移交立即标记失效、样本回到待复核，确认修订后须重新办理入库；驳回则恢复入库。所有旧版仍可查，且历史旧版不会重复计入潜次清单。
- **审潜分离**：复核人不得与潜水员相同。
- **一致的筛选/时间线/导出**：筛选条件、视图和选中项均持久化，刷新后保持；时间线按潜次分组，每潜次只列样本当前版本（旧版与修订事件挂在同一样本下，不会混入其他潜次清单）；导出 JSON 与当前筛选、清单、时间线口径一致。

## 操作说明

- 点击沉船平面图空白处或「登记新样本」进行出水登记；点击标记查看详情。
- 详情中依次办理：封存复核 → 确认/驳回待确认修订 → 入库移交；已入库样本可发起再修订。
- 顶部「导出JSON（按当前筛选）」导出与当前筛选一致的快照（含 versions 留档与移交记录）。
